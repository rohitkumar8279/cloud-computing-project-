How it works

  1. This page is a static file served by Cloudflare. There is no web server to run.
  2. When you submit the form, the browser calls POST /api/complaints. A Worker (a serverless function) validates the data and saves it to D1, a serverless database.
  3. Admin actions send an x-admin-key header, and the Worker checks it before changing any data.
  4. A cron trigger wakes the Worker every day at 8:00 AM IST, counts the complaints and stores a report row.
  5. Nothing runs between requests, so nothing is used while idle.

AWS equivalent: Worker = Lambda · API route = API Gateway · D1 = DynamoDB · Cron trigger = EventBridge schedule.
